# Baula — sitio oficial

Repositorio de la landing oficial de Baula. Proyecto en preparación; todavía no contiene una web ni despliegue configurado.

## Flujo de trabajo

1. Definir el alcance y los contenidos públicos.
2. Trabajar en ramas `codex/<cambio>`.
3. Abrir una pull request con resumen y validaciones.
4. Revisar la vista previa y registrar la aprobación del responsable.
5. Incorporar a `main` y publicar únicamente con autorización explícita.

La creación inicial de estos archivos es la excepción necesaria para inicializar el repositorio vacío.

## Entorno previsto

Astro + TypeScript para la landing; Cloudflare Workers Static Assets para alojamiento. Confirmar la arquitectura al definir formularios e integraciones.

Ver [la guía del entorno](docs/ENTORNO.md) y [las reglas para Codex](AGENTS.md).

## Información pública

Este repositorio es público. No subir documentos internos, contraseñas, tokens, datos de clientes ni archivos de trabajo privados. Los materiales de marca deben contar con autorización para publicación.
